Fremdeigentumslager - Lagergruppen für Zugänge von Geschäftspartnern ohne Eigentumsübergang

Sie können Lagerplätze als Fremdeigentum definieren, deren Zugänge zu den Bestandsmengen dieser Lagerplätze den Mischpreis nicht verändern.

Der Zugangsbestand des Fremdeigentumslagers ist der Bestand eines Materials, den ein Lieferant Ihnen als Abnehmer zur Verfügung stellt. Die Vorräte lagern physisch beim Abnehmer, bleiben aber vorerst das Eigentum des Lieferanten. Erst bei der Entnahme aus dem Konsignationslager entsteht gegenüber dem Lieferanten eine Verbindlichkeit. Entsprechend ist ein Fremdeigentumslager oder ein -lagerplatz das Warenlager oder der Warenlagerplatz eines Lieferanten, das sich im Unternehmen des Abnehmers befindet.

Erfassung der Fremdeigentumslagergruppe für Zugänge

Mit dem Feld Fremdeigentum in der [Lagergruppe] steuern Sie, ob dort Fremdeigentumsbestände geführt werden sollen (markiert) oder nicht (Feld ist leer). Dazu muss zumindest ein Lagerplatz für Fremdeigentum bestimmt und eine Lagergruppe dafür vorhanden sein.

  • Beim Erfassen dieser Lagergruppe muss das Feld Fremdeigentum markiert werden. Alle Lager und Lagerplätze, die dann zu dieser Lagergruppe gehören, gelten für Zugänge zum Fremdeigentumslager. Sie können auch mehrere Lagergruppen für Fremdeigentum erfassen. Ist die Lagergruppe einem bestimmten Geschäftspartner zugeordnet, kann das ebenfalls eingetragen werden. Dazu muss ebenfalls das Feld Konsignationslager markiert werden.

  • Eine Lagergruppe für Fremdeigentum muss eine externe Lagergruppe sein.

Erfassung einer Konsignationslagergruppe für Kunden und Lieferanten

Das Gegenstück zum Fremdeigentumsplatz stellt Ihr Konsignationslager bei einem Kunden oder bei einem Lieferanten / Lohnfertiger (für Beistellteile) dar. Die Lagergruppe kann als Konsignationslagergruppe gekennzeichnet werden. Diese Kennzeichnung wird vom Infosystem 10573 CONSWAREHOUSE ausgewertet.

Ein Konsignationslager für Kunden oder Lieferanten kann wie folgt eingerichtet und genutzt werden:

  1. Sie erfassen eine eigene Lagergruppe, ein Lager und einen Lagerplatz für einen Kunden bzw. Lieferanten, damit das Konsignationslager getrennt von allen anderen Lagergruppen disponiert wird. Hier kann die Disposition z.B. auch eine Mindestbestandsüberwachung durchführen. Eigene Lagergruppen können im Feld Geschäftspartner den Verweis auf den Kunden oder Lieferant erhalten.

  2. Den Lagerplatz tragen Sie als Konsignationslagerplatz in [Kunde] bzw. [Lieferant] ein.

  3. Sie erfassen einen Kundenauftrag bzw. eine Bestellung. Darin werden die Standard-Abgangslagerplätze der eigenen Lagergruppe verwendet, also die Lagerplätze, die vorgeschlagen werden.
  4. Die Lieferung entspricht einer Umlagerung.
  5. Bei der Entnahme von Material aus dem Kundenkonsignationslager schickt der Kunde nun eine Gutschrift. Sie erfassen daraufhin eine Verkaufsrechnung für ihn, indem Sie als Rechnungsart Rechnung wählen und mit Mit Lagerbewegung markieren. In die Rechnung werden die entnommenen Artikel, die Entnahmemenge und als Entnahmeplatz der Konsignationslagerplatz des Kunden eingetragen, so dass das entnommene Material von diesem Platz abgebucht wird. Durch die Rechnung wird ein offener Posten erzeugt, der nach Bezahlung um- bzw. ausgebucht werden kann.
Der Konsignationslagerplatz wird auch in Bestellvorschlägen für Beistellungen ermittelt und eingeplant.

Sie können für jeden Kunden oder Lieferanten eine eigene Lagergruppe einrichten, insbesondere dann, wenn zu verschiedenen Lieferanten gleiche Beistellteile umgelagert werden. Befinden sich diese Bestände in einer gemeinsamen Lagergruppe und unterscheiden sich nur durch den Lagerplatz, kann die Disposition, die nur Gesamtbestände innerhalb einer Lagergruppe berücksichtigt, diese Zuordnung nicht beachten. Die dispositive Trennung von Lagergruppen dagegen führt zuverlässig zur eindeutigen Zuordnung.

Buchung, Mischpreis und Disposition

Wird einem Fremdeigentumslagerplatz eine Menge zugebucht, wird der Artikelmischpreis nicht aktualisiert, sondern ist 0 für alle Zugangsmengen. Wird einem Zugangslagerplatz außerhalb des Fremdeigentumslagers eine Menge zugebucht, wird der Mischpreis aktualisiert. Beim Berechnen des Artikelmischpreises wird allerdings der Artikelbestand um die Bestände reduziert, die Fremdeigentum sind. Damit wird z.B. Kundeneigentum nicht im aktuellen Lagerwert berücksichtigt.

Fremdeigentumsbestände sind dispositionsrelevant, wenn der entsprechende Lagerplatz als Dispositionslagerplatz markiert wird. Soll ein Bestand durch die Disposition überwacht werden, wird folgende Beschaffungsart empfohlen:

  • Beschaffungsart Fremdbeschaffung in den Fremdeigentumslagergruppen (Feld Beschaffungsart in den Lagergruppeneigenschaften)

  • Beschaffungsart Umlagern in der internen Lagergruppe (Feld Beschaffungsart im Artikel).

Wird der Mindestbestand unterschritten, generiert die Disposition

  • Bestellvorschläge für die Lagergruppe für Fremdeigentum
  • Umlagerungsvorschläge für die interne Lagergruppe.
Lagerplätze mit Fremdeigentum

Bewegungen von Artikeln auf Lagerplätze mit Fremdeigentum verursachen keine wertmäßigen Bestandsveränderungen.
Rückmeldungen bezüglich (Lieferanten)-Konsignationslagerplätzen werden bewertet, es werden aber keine Buchungen durch die Funktion Materialkostenverbuchung erzeugt.
Fertigungskosten dagegen werden auch in Fremdeigentumslagern immer verbucht. Material, das für so eine Fertigung auf Fremdeigentum umgelagert wird, muss mit Materialkostenwunsch verbucht werden, um den Abgang zu buchen.


Felder Fremdeigentum, Konsignationslagerplatz

Fremdeigentum

Ist dieses Feld markiert, gelten alle Lager und Lagerplätze, die zu dieser Lagergruppe gehören, als Konsignationslager oder -lagerplätze für Zugänge von Fremdeigentum.

Im Einkauf kann auch unsere Firma ein Konsignationslager betreiben. Lieferanten können die Lagerplätze der Lagergruppe beliefern. Aus unserer Sicht lagert auf diesen Lagerplätzen Fremdeigentum. Dem Lieferanten gehört die Ware noch, bis wir sie entnehmen. In diesem Fall, muss das Feld Fremdeigentum markiert werden.

Schreibgeschützt nach Erfassen
Dieses Feld kann nur beim Erfassen markiert werden. Nach dem Speichern einer Lagergruppe ist dieses Feld schreibgeschützt.

Konsignationslager, Geschäftspartner

Durch Markierung des Feldes bestimmen Sie die Lagergruppe als Konsignationslager für den Geschäftspartner, den Sie eintragen. Die Verkaufsvorgänge, die ein Konsignationslager betreffen, werden über das Infosystem 10573 CONSWAREHOUSE erfasst im Zuge der Konsignationslagerregelung für EU-Länder. Ein Geschäftspartner kann nur eingetragen werden, wenn die Lagergruppe als Konsignationslagergruppe gekennzeichnet ist.

Standardlagerplätze Verkauf

Tragen Sie hier die Lagerplätze ein, die für die Artikel aus Rücklieferungen und Kundenanlieferung standardmäßig benutzt werden sollen.

  • In das Feld Rücklieferung können keine Lagerplätze eintragen werden, die zu einer Konsignationslagergruppe gehören.
  • In das Feld Kundenanlieferung können nur Lagerplätze eintragen werden, die zu einer Konsignationslagergruppe gehören.

Wenn eine Kundenanlieferung im Verkauf erfasst wird, dann wird der Feldinhalt der aktuellen Lagergruppe als Lagerplatz der Kundenanlieferungspositionen übernommen.

Wenn ein Rücklieferschein im Verkauf erfasst wurde, dann wird der Feldinhalt der aktuellen Lagergruppe als Lagerplatz der Rücklieferpositionen übernommen.
